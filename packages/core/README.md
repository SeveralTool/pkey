# `@pkey/core`

Shared TypeScript domain: vault types, crypto (PBKDF2/HKDF/TOTP), sync merge/delta, importers/exporters, statistics, autofill matching, **password generator**.

No React Native APIs. Mobile and the PWA both import this package.

```bash
npm run test:core
npm run build:core
npm run check:core-purity
```
